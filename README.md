# Exercícios de Python

Este repositório contém soluções para diversos exercícios de Python, organizados por tópicos de estudo. Cada pasta refere-se a um conjunto de exercícios abordando diferentes aspectos da linguagem Python.

## 📂 Estrutura de Pastas

- `aula 1/` - Exercícios do primeiro conjunto de tópicos.
- `aula 2/` - Exercícios do segundo conjunto de tópicos.
- `aula 3/` - E assim por diante...

Cada pasta contém os arquivos Python correspondentes aos exercícios da respectiva seção.

## 📝 Sobre os Exercícios

Os exercícios abordam os seguintes temas:

- Sintaxe básica do Python
- Estruturas de controle
- Funções
- Programação Orientada a Objetos
